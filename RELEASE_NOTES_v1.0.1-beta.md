# DBD Overlay Studio — Beta 1.0.1

Primeira release pública de teste do DBD Overlay Studio.

## Principais recursos
- Overlay WinStreak com vários layouts e Mini Estilos opcionais.
- Overlay de Confronto com layouts horizontais e verticais.
- Personalização de nomes, placares, INFOs, SET / MAP, cores, fontes, brilho e tamanho.
- Killer do Set com imagem, nome, posição e fundo personalizável.
- Posicionamento e redimensionamento visual das overlays.
- Uma única URL local para uso no OBS em 1920×1080.
- Paleta de cores prontas e seletor de cor personalizado.
- Temas de interface e suporte a Português, English e Español.
- Atalho configurável para incrementar a WinStreak.
- Aplicativo na bandeja do Windows e bloqueio de múltiplas instâncias.

## Observação
Esta é uma versão Beta de teste. O aplicativo ainda não possui assinatura digital, então o Windows ou o navegador podem exibir avisos de segurança durante o download ou instalação.
