# DBD WinStreak & Match Overlay — Beta 2.4.0

## Mudança de direção
Todo o módulo de overlay de mapas foi removido desta build:
- sem aba Mapas;
- sem janela de mapa;
- sem catálogo/maps.js;
- sem pasta de imagens de mapas;
- sem rotas HTTP de mapa;
- sem controles de mapa na aba Posição;
- sem mapa no Browser Source do OBS.

## WinStreak
A WinStreak continua com os 14 estilos e personalizações da 2.3.5.

## Nova Overlay de Confronto / Times
Primeiro protótipo para mostrar os TIMES que estão jogando uma partida — não é uma overlay de campeonato.

Inclui:
- Time esquerdo e time direito;
- placar independente;
- texto central configurável (ex.: CONFRONTO, AMISTOSO, MD3);
- cores independentes dos dois times;
- cor de fundo e cor de texto;
- 5 estilos iniciais: Broadcast Duel, Arena Pill, Scoreline, Esports Frame e Versus Gradient;
- liga/desliga independente;
- posição e tamanho próprios;
- borda/handles vermelhos no modo de edição.

## OBS
A mesma Browser Source 1920x1080 continua sendo usada.
Ela pode exibir WinStreak, Confronto ou ambos, conforme os switches do app.
