# DBD Overlay Studio — Beta 2.6.1

Foco desta build: Confronto, Posição e tradução.

## Confronto
- Time A / Time B compactados.
- Defaults: Time A azul, Time B verde, placar 0–0.
- Sistema automático removido da interface nesta etapa.
- Informações da partida ficam logo abaixo dos times.
- Cada rótulo tem: visibilidade + rótulo/cor + UM campo de texto.
- Linha inferior mantida; padrão novo: `MAP / MATCH`.
- Killer do Set movido para depois das informações.
- Visual compactado.

## Posição
- Botão `Ativar para arrastar` voltou.
- `Salvar / Bloquear` permanece e fica verde quando há mudança de posição/tamanho.
- Botão `Fechar aplicativo` encerra o processo definitivamente.
- Arrastar continua liberado até salvar/bloquear ou sair da aba.
- Limite de monitor e snap suave mantidos; o snap espera uma pausa real antes de corrigir a borda.

## Idiomas
- Seletor Português / English / Español agora altera efetivamente os textos do editor.
